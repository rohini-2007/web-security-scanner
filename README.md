# Smart Waste Management System

A web-based solution for smarter and cleaner waste management.

**Submitted by:** Waghade Rohini Shivaji (Roll No. 77)
**Live demo:** https://rohini-2007.github.io/smart-waste-management/

---

## Overview

Rapid urbanization and population growth have increased the amount of waste produced in cities. Many people do not know how to segregate waste properly, and collection is often not planned around how full the bins are.

This project is a Smart Waste Management Website built with HTML, CSS and JavaScript. It creates awareness about waste segregation and shows how bin status can be monitored through a simple, easy-to-use web interface.

## Problem Statement

- **Overflowing bins:** Bins are emptied on fixed schedules, so some overflow and cause odour and unhygienic conditions.
- **Poor segregation:** People mix wet, dry and hazardous waste because they lack clear and simple guidance.
- **Lack of visibility:** There is no single place where users or administrators can see the status of bins.
- **Low awareness:** Many citizens do not know about recycling, reuse and the benefits of smart waste systems.

## Objectives

- Create awareness about waste types, correct segregation and recycling.
- Display bin fill levels on a dashboard using JavaScript, with alerts for full bins.
- Build a clean, responsive interface that works on mobile and desktop.
- Provide a contact/feedback section so users can report problems and give suggestions.

## Features

- Information on waste categories, segregation tips and recycling
- Bin status display that highlights bins that are full or nearly full
- Alerts for full bins
- Navigation menu and form validation
- Feedback/complaint form for public participation
- Responsive design for mobile and desktop

## Technology Stack

| Layer | Technology Used |
|---|---|
| Structure | HTML5: pages, headings, sections, forms and navigation |
| Styling & Layout | CSS3: colours, flexbox/grid layout, responsive design, hover effects and animations |
| Logic & Interactivity | JavaScript: DOM manipulation, event handling, form validation and bin status display |
| Hosting | GitHub Pages (free static website hosting) |

## System Workflow

1. **Visit:** The user opens the website link on a mobile or desktop browser.
2. **Explore:** The user reads about waste categories, segregation tips and recycling.
3. **Monitor:** JavaScript shows the bin status and highlights bins that are full or nearly full.
4. **Respond:** The user submits feedback or a complaint, and the administrator takes action.

## Target Users

Residents, housing societies, students and college campuses, municipal staff and waste collectors who want a simple way to learn about and track waste management.

## Expected Impact

- **Better awareness:** Users learn how to segregate and recycle waste correctly.
- **Cleaner surroundings:** Quick bin status updates help reduce overflowing bins.
- **Easy access:** No installation is needed; the site works on any device with a browser.
- **Foundation for smart city work:** The website can grow into a complete smart waste system.

## How to Run

1. Download the `Source_Code` folder.
2. Open `index.html` in any web browser.

Or visit the live demo: https://rohini-2007.github.io/smart-waste-management/

## Challenges

As a static website it has no database or backend, so data cannot be saved permanently or updated from real sensors yet.
